Ambient Focus Timer • Case Study

What is it?

A distraction-free productivity timer that uses gentle color shifts and ambient motion to indicate focus intervals and break periods without loud alarms or busy dashboards.

Why I Made It

I needed a reliable companion tool for writing code and playing piano without jarring alarm sounds. The application is built to sit quietly in the background for hours like a digital room with a clock inside it.

The Process & Technical Notes

Focused heavily on CSS keyframe gradient breathing in sync with natural pacing. Timer accuracy is calculated using precise unix timestamps (`Date.now()`) rather than drift-prone `setInterval` timers, ensuring absolute accuracy even when laptop sleeps, browser tabs are inactive, or the app is offline.

Keyboard Shortcuts

  • Space — Start / Pause timer
  • R — Restart session
  • F — Toggle Fullscreen Focus mode
  • Esc — Exit Focus mode
